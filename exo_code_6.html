  • Il est demandé de créer une classe Stage caractérisée par un identifiant (entier), un domaine, et un type, un étudiant et une entreprise.
        Les attributs doivent être nommés comme suit :
           -  identifiant: pour l'identifiant du stage,
           - domaine: pour le domaine du stage,
           - type : pour le type du stage.
           - etp: pour l'entreprise proposant le stage.
           - etu: pour l'étudiant effectuant le stage.
  • L’ordre des attributs dans le constructeur de la classe doit respecter l’ordre indiqué dans le cahier des charges.
  • Toutes les caractéristiques doivent être affichables et modifiables.
  • La création d’un stage ne peut se faire qu'en fournissant toutes les caractéristiques.
  • Créer une méthode "AffichageStage" permettant d'afficher les caractéristiques d'un stage à savoir:
        l'identifiant, le type, le domaine,le nom de l'étudiant, son prénom, son téléphone, le nom de l'entreprise et son téléphone.
